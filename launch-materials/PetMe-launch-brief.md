# PetMe 开店网站简要说明 · Website Launch Brief

PetMe 使用 **MoeGo** 管理预约、可用时段、客户姓名、电话、邮箱和宠物资料。**PetMe 官网由我们独立制作**，建议用 React + Next.js，使用自己的域名来展示品牌、服务价格和美容作品。顾客通过 Google、门店二维码或网址进入官网，再从 **Book an Appointment** 进入 MoeGo 查看可约时间并预约。当天无位时，顾客可以继续查看其他日期。首版由 MoeGo 托管预约资料，省去自建数据库和 Java 后端。

PetMe will use **MoeGo** for scheduling and client and pet records. A **separately built PetMe website** on its own domain will show services, prices, and grooming photos. Customers can find it via Google, a printed QR code, or the website address, then start a MoeGo booking from the site. The launch can run with MoeGo handling the booking data and server-side scheduling.

正式域名 · Production domain: `www.petme.ca`
